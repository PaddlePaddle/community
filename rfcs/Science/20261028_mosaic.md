## 1. 概述

### 1.1 相关背景

将 [(Sparse) Attention to the Details: Preserving Spectral Fidelity in ML-based
Weather Forecasting Models](https://arxiv.org/abs/2604.16429)（ICML 2026）的
[Mosaic](https://github.com/maxxxzdn/mosaic) 迁移到 PaddleScience，提供可复用的
全球概率天气预报架构及官方权重运行路径。

### 1.2 功能目标

1. 实现并注册 `ppsci.arch.Mosaic`，覆盖 HEALPix U-Net、网格插值、上下采样、
   局部/压缩/选块注意力、GQA、RoPE、噪声条件 FFN。
2. 提供官方 ERA5 checkpoint 转换、真实数据提取、独立推理和自回归滚动。
3. 提供 LoRA、MSE/MAE/fair-CRPS 可训练性诊断、天气评估和 CINN benchmark。
4. 提供单元测试、双语官网案例、复现环境及验证记录。

### 1.3 意义

为 PaddleScience 增加兼顾全局建模和局部细节的概率天气预报架构。
选块 gather 保留稀疏计算结构，并通过分块与重计算控制显存需求；
在 Paddle 推理中不引入 PyTorch 或原 Triton 自定义内核依赖。

## 2. PaddleScience 现状

当前 develop 已包含 FourCastNet、GraphCast、ClimaX 等气象模型，尚无 Mosaic。
采用现有 `ppsci.arch.base.Arch` 的字典输入输出及注册机制，不修改已有模型。
示例通过命令行参数和 checkpoint config.json 管理运行参数与模型配置。

## 3. 目标调研

原仓库锁定 commit `30c5baef1dc76c5810caf84c449e46c7925b9aec`，Apache-2.0。
官方权重源为 `AMLab-UvA/mosaic`，锁定 revision
`c2aaa3e0799e2a0e8fba8c79beb6d3ba8e2a4954`。ERA5 基座214,184,448参数，
两帧24h间隔的历史，240×121经纬网格，82变量，24h单步预报。

模型在经纬度和嵌套 HEALPix 网格间插值，使用多尺度 U-Net Transformer，
通过局部、压缩及 top-k 选块 attention 保留细节。主要迁移难点为原始
FlashAttention/Triton 内核的数值路径、GQA 路由分组、几何缓冲区和训练显存。
本实现采用可微 Paddle 算子实现注意力，任务指标与原版参考进行对照验证。

## 4. 设计思路与实现方案

- `ppsci/arch/mosaic.py`：配置、HEALPix 几何、插值、上下采样及主网络。
- `ppsci/arch/mosaic_attention.py`：RMSNorm、RoPE、GQA、选块 attention 和 FFN。
- `ppsci/arch/__init__.py`：注册 Mosaic。
- `examples/mosaic`：转换、数据提取、推理、滚动、LoRA/CRPS 训练诊断、评估、
  对齐及编译器诊断。参考 Torch 仅用于离线转换/验证，不用于 Paddle 推理。
- `test/arch/test_mosaic*.py`：数学 attention 值/梯度、几何和 checkpoint、
  LoRA、重计算、fair-CRPS 及天气聚合回归。
- `docs/{zh,en}/examples/mosaic.md` 及 mkdocs 导航：官网案例入口。

API 示例（config 为转换器保存的配置字典）：

```python
model = ppsci.arch.Mosaic(config)
model.initialize_static_vars(static_values, longitude, latitude)
model.initialize_interpolation(longitude, latitude)
model.set_state_dict(paddle.load(checkpoint_path))
model.eval()
with paddle.no_grad():
    prediction = model({"state": state, "time": time, "noise": noise})["forecast"]
```

`state` 为 `[B,N,history,lon,lat,C]`，`time` 为 `[B,N,2]`，可选显式 `noise`
为 `[B*N*samples,noise_dim]`；输出为归一化预报。切换网格需重新初始化几何。

### 4.1 补充说明

选块 KV 使用 query chunk gather，避免构造全局 token×token 矩阵。
保留原版 GQA top-k 的非直观 head 分组。路由不求梯度，与原版一致。
原版几何65个 buffer 可导出并严格按名称/形状/dtype/有限值验证后转换。
权重按 Linear 模块名称转置，含方阵，不用形状猜测。
静态场统计使用 FP64 累积，修正完整网格 FP32 归约偏差。

LoRA 默认目标为 attention Q/V 与 FFN 两个线性层，rank8/alpha16共1,837,056
可训练参数；冻结基座。重计算覆盖阶段、attention 与插值分块。
fair-CRPS 使用原版无偏成员配对公式，避免分配完整成员平方的空间张量。
训练验证采用固定上下文与显式噪声，检查梯度、参数更新及适配权重保存加载。

## 5. 测试和验收的考量

验证覆盖结构前反向对齐、官方权重转换、真实天气预报、LoRA参数更新和CINN加速。
天气指标采用物理量空间的余弦纬度加权RMSE；表中退化比例为相对原版参考的
RMSE变化，正值表示误差增加。实验使用的日期、时效及硬件随结果列出。

| 检查 | 已有证据 |
| --- | --- |
| CPU单测 | 11项通过；选块attention独立dense mask值/梯度，checkpoint/几何、LoRA和重计算、CRPS、天气聚合 |
| 小模型数学对齐 | CPU/GPU三步SGD；前向max<2e-7、梯度max<9e-8 |
| 官方权重 | SHA256校验，131/131参数组；214,184,448基座参数 |
| 冬季24h | 三初始化日期×82变量最差RMSE相对退化0.546171% |
| 自回归 | 单初始化24/48/72h最差0.439738%/0.893076%/0.793012%，无真值反馈 |
| 春夏秋24h | 三季各一个初始化日期，最差RMSE相对退化1.552577%/1.042044%/0.017902% |
| LoRA | 完整分辨率训练、适配梯度有限、冻结基座哈希一致、adapter往返一致 |
| 两成员fair-CRPS | 十步SGD：0.081527159→0.081524864；峰值allocated19.6GiB |
| 完整CINN | RTX3090；动态1.465533s、编译1.191436s，吞吐+23.0056%；首次226.332s |

CINN复用同图检查三个真实输入，相对动态图的最差天气RMSE退化0.00108478%。
性能计时使用样本0，warmup3/steps10并同步GPU。
原版参考采用原Triton稀疏注意力及Torch SDPA；
完整环境、运行命令和数值差异记录见实现分支的`examples/mosaic/VALIDATION.md`。

## 7. 影响面

新增架构导出、独立示例、测试及双语文档。healpy仅在Mosaic构建/几何初始化
时导入，普通 `import ppsci` 不要求加载healpy；不将Torch加入基础依赖。
不提交权重、真实天气二进制、机器专属路径或私有资料。
默认仍为可微数学attention和动态图推理；CINN为可选诊断。
原代码Apache-2.0出处在模型头部及示例文档标明，示例依赖单列。
