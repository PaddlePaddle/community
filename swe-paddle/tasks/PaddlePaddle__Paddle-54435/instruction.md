# 支持按节点 IP 确定分布式 launch 的节点顺序

## 详细描述

分布式 launch 在多节点任务中需要汇总各节点信息，并为未显式指定 rank 的节点确定顺序。当前顺序依赖 rendezvous 中已有的键或节点注册结果，节点启动顺序发生变化时，同一组机器可能得到不同的节点 rank。

需要增加一个可选配置，使用户可以按节点 IPv4 地址确定节点顺序。启用后，各节点应按照 IP 地址的数值顺序获得一致的节点列表和对应 rank；HTTP master 与 ETCD master 两种同步方式应保持相同结果。未启用该配置时，继续使用现有排序和 rank 分配行为。

## 验收说明

- launch 参数和对应环境变量均可控制是否按 IP 排序。
- 启用后，HTTP master 与 ETCD master 都按 IPv4 地址的数值顺序返回节点列表，并为当前节点返回正确 rank。
- 未启用时，原有节点顺序、显式 rank 和其他 launch 参数行为保持不变。

## 技术要求

- 熟悉 Python 参数和环境变量处理。
- 熟悉 PaddlePaddle 分布式 launch 与节点同步流程。
- 了解 IPv4 地址比较和分布式节点 rank 分配。
