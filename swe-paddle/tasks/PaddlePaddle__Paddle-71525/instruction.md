# 为 SOT 信息报告增加可逆序列化能力

## 详细描述

SOT 可以收集 breakgraph reason、subgraph 等诊断信息，但这些信息目前只能输出面向人工阅读的文本摘要。开启机器可读报告后，调用方无法得到边界明确、可传输并能恢复为等价信息对象的输出，因而不能可靠地聚合或分析日志。

需要让诊断信息支持结构化序列化与恢复，同时保留默认文本报告行为。序列化后的输出应能够安全嵌入日志，恢复后仍保留异常类别、原因数量、子图名称、算子数量以及按配置决定的详细图信息。

## 验收说明

- 普通字典数据应能完成编码和解码往返，恢复结果与原始内容相等。
- breakgraph reason 报告应保留原因类别、内容和分类计数，并能恢复为等价的诊断记录。
- subgraph 报告应保留每条记录的名称和算子数量；启用详细信息时还应保留图内容，默认文本摘要行为应继续有效。

## 技术要求

- 熟悉 Python 结构化数据序列化与安全日志编码
- 熟悉 Paddle SOT 信息收集和环境配置机制
- 熟悉异常类型恢复、对象相等性与向后兼容设计
