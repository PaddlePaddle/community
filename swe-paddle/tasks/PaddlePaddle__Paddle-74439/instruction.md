# 为 Paddle 增加 ravel 张量展平接口

## 详细描述

Paddle 当前缺少与常见张量库兼容的 `ravel` 公共接口。用户需要能够通过公共命名空间将任意维度的 Tensor 展平成一维结果，包括标量、一维、多维以及包含零长度维度的 Tensor，同时保持元素顺序不变。

## 验收说明

- `ravel` 应可通过公共 Paddle API 使用，并返回一维展平结果。
- 标量、一维、多维和空 Tensor 都应得到与完整展平语义一致的结果，元素顺序保持不变。
- 已有 `flatten` 行为应保持兼容，不因新增接口产生回归。

## 技术要求

- 熟悉 Python API 设计与模块导出机制。
- 理解 Tensor shape、rank 和完整展平语义。
- 能够保持现有 API 兼容性并处理标量及零长度维度等边界输入。
